## What I worked on

- Fixed bug: weapon sprite didn't reappear after unequipping and re-equipping a weapon during combat
- Added `_weapon_visible: bool = false` to `player.gd` to track intended visibility state across equip/unequip cycles; `set_weapon_visible()` now stores the value before applying it; `_setup_equipment()` uses `_weapon_visible` instead of hardcoded `false`

- Fixed `ClassList` layout in `game.tscn`: added `custom_minimum_size = Vector2(0, 120)` and `size_flags_vertical = 3` (FILL + EXPAND)
- Verified full flow: Start → character creation → Warrior selectable → Continue → world map with initialised player stats

## Key decisions made

- Embedded panel nodes directly in `game.tscn` rather than as separate `.tscn` files — keeps the scene count low while the panel layouts are still being iterated
- Class resources loaded from `res://resources/classes/` at runtime as a fallback rather than relying solely on the Inspector export — more robust to UID cache issues and better for adding classes later without touching the scene

## Blockers / struggles

- Godot's UID cache didn't recognise the new scripts (`character_creation_panel.gd`, `level_up_panel.gd`, `player_class_data.gd`) because they were created outside the editor. This silently broke typed `Array[PlayerClassData]` assignment via scene serialisation. Worked around with a runtime directory scan.
- `ItemList` in a `VBoxContainer` collapses to zero height with no explicit size — not obvious because `item_count` was correct and only the rendering was broken.
