## Key decisions made

- `WorldMapNode` owns event generation — holds scene refs + json dirs per event type, picks randomly from files in each dir. Adding JSON files expands the pool automatically.
- Removed `event_json_path` exports from all event subclasses. Events now receive a pre-parsed `Dictionary` via `initialize(data)` on the base `Event` class. File I/O moves up to the node.
- World map is a persistent GUI panel — hidden during dungeons, forced open on dungeon complete. `gui.gd` relays `node_selected` to `game.gd` following existing signal relay pattern.
- `game.gd` owns the dungeon event queue (`_pending_events`, `_event_index`). `_on_event_complete()` drives progression through the queue; when exhausted, calls `_on_dungeon_complete()`.
- Miniboss always fills the last slot in the generated event list — separate export (`miniboss_scene` + `miniboss_json_path`) so it's never drawn from the random pool.
