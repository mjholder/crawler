## Riders split into two orthogonal DoT levers + preview fix (later 2026-08-04)

Live-testing Serpent's Kiss surfaced two things. (1) The engine's single `stacks` number does double
duty on a `stack_decays` DoT — it's both the lifetime AND the per-tick multiplier — so `StackBonusRider`'s
+1 read as "potency" (a bigger first tick) as much as "duration." (2) The **attack preview** lied: it
printed the authored `duration` (poison = 3) as the "(N)" and ignored the equipped rider entirely, so
Stab previewed "(3)" while the real hit was "poison x2 (2)". (The *live* status readout,
`gui._status_tooltip`, was already correct — it uses `turns_remaining`.)

Fixes:
- **Split the rider into two orthogonal levers** (design decision, see [[design.md]]): kept
  `StackBonusRider` as the **longer** lever (+stacks → +turns), added **`PotencyRider`** (`potency_bonus`)
  as the **harder** lever (+flat per-stack tick damage, same duration). Threaded `potency_bonus` through
  `weapon_context_for` → `StatusEffect.apply` → `Combatant.apply_status` onto a new persistent
  `StatusInstance.potency` (weapon context is gone by tick time); `DamageEffect.apply_tick` /
  `BurstDamageEffect.apply_tick` add it per stack, before the stack multiply. Potency is NOT crit-scaled
  (crit deepens stacks, not the edge); on re-apply the strongest potency wins.
- **Preview truthfulness** (`attack_preview.gd`): fold the weapon's `bonus_stacks` into the previewed
  count, and for `stack_decays` statuses show the real lifetime (= stacks), not `duration` — mirroring
  the live readout.
- Content: new `resources/riders/virulent.tres` (PotencyRider); `venomous.tres` stays a StackBonusRider
  with its description re-pointed at "lasts longer." Serpent's Kiss now bakes **Virulent** so it
  demonstrates the potency lever.
- Tooling: `PotencyRider` added to the exporter allowlist (`make schema` → 41 classes) and the editor's
  ＋New rider picker; `mcp-authoring.md` updated. Frontend rebuilt.

Verified: `make schema` (41 classes, PotencyRider present), `make verify` (149/149), headless test —
plain poison tick=1; Virulent tick=2 at *1 stack* (harder, not longer); a StackBonusRider poison ramps
2,1 over 2 turns; COMMON gates the rider to 0; preview reads "(1)" fresh and "x2 (2)" with a stack rider.
