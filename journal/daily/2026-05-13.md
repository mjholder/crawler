## Key decisions made

**SpellButton as a separate scene** — the current `rebuild_action_buttons()` in `gui.gd` creates plain `Button.new()` for both attacks and spells. Splitting spells out into a dedicated `SpellButton` scene lets us show an icon, name, and MP cost in a custom layout rather than a single text string like `"Fireball (10)"`. The integration contract stays the same: `SpellButton` is still a `Button` subclass, so `pressed` wires to `attack_requested` identically. `gui.gd` just needs one `@export var _spell_button_scene: PackedScene` and a branch swap in `rebuild_action_buttons`.
