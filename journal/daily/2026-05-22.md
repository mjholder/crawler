## Key decisions made

- Hybrid storage: `DialogueData.tres` wraps JSON, positions in `.tres`, tree in `.json` — see [[design.md]] entry dated 2026-05-22
- `node_positions_json: String` (JSON-encoded) instead of `Dictionary` — avoids Vector2 serialization complexity through io_write.gd; the custom editor encodes/decodes it directly
- Each source handle on a node card is per-choice (`choice-0`, `choice-1`, …); one outgoing edge per handle enforced on `onConnect`
- Edges are the source of truth for `choice.next` on save — the JSON node's `choices[i].next` is rebuilt from outgoing edges, not stored as form state
