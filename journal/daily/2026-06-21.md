## What I worked on

Built Phase 2 shrine ascension end-to-end. The player-side machinery (`ascend_patron()`, `_patron_tier_index`, replace-not-stack) was already shipped in Phase 1, so this session was the in-world trigger: event, UI, and map placement.

- **`Player` accessors** — added `get_patron`, `can_ascend_patron`, `get_active_tier`, `get_next_tier` so the event reads saint state through a public API instead of poking private fields.
- **`ShrineEvent`** (`scripts/shrine_event.gd` + `scenes/shrine_event.tscn`) — generic, reads the active saint at runtime; emits `shrine_requested(...)`, resolves a choice via `on_shrine_choice(ascend)`. On ascend it charges the gold tithe (`spend_gold`) then `ascend_patron()`.
- **`ShrineMapNode`** (`scripts/shrine_map_node.gd` + `scenes/world_map_node_shrine.tscn`) — mirrors `ShopMapNode`; exports `shrine_scene` + `ascension_cost`, bypasses the floor pool. Placeholder art = rest node icons.
- **`ShrinePanel`** (`scripts/shrine_panel.gd` + subtree in `game.tscn`) — shows next-tier name/description/stat-diff + tithe; Ascend disabled when broke; silent-shrine fallback (no saint / final tier).
- **Wiring** — `gui.gd` (`shrine_ascend_requested`/`shrine_leave_requested`, show/hide methods) and `game.gd` (`_on_shrine_requested`, ascend/leave routing).
- **World map** — placed `WorldMapNodeShrine` as a between-acts checkpoint; the three act-1 end nodes now funnel through it into the boss.

Verified the whole project parses clean via `godot --headless --check-only` (after a `--import` to register the new `class_name` scripts).

## Key decisions made

- **Shrine = hand-placed between-acts checkpoint**, not a random floor-pool roll — simplest path, no "act" concept needed, and leaves room to grow the node into a hub later.
- **Cost model:** ascending costs gold (a coin tithe on top of the next tier's built-in steeper stat penalties); declining keeps gold and current tier. No reward for declining.
- **Generic runtime shrine** reads `player.get_patron()` / tier index — one shrine works for every saint.
