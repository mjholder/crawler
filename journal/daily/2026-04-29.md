## Key decisions made

- Weapon layer sits between `TorsoLayer` and `HandsFrontLayer` — sibling order is draw order in Godot, so this gives the axe the correct depth (over torso/legs, under front arm)
- Used `paper_doll_front` only (no `paper_doll_back`) for the weapon — single static sprite is sufficient for a melee weapon held in one hand
- `HealEffect` evaluates expression against **target** (heal scales with recipient's pool — `max_health`, `health` added to variable vocabulary); `DamageEffect` still evaluates against **source** — consistent with "damage comes from attacker, healing goes to recipient"
- Consumable dispatcher remains a separate function from `_on_player_attack_performed` — the non-turn-ending invariant is preserved, and both functions are now a parallel ~5-line loop calling `effect.apply(source, target)` (see design.md update)
