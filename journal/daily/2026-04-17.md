## Key decisions made

- **Intercept victory at the event layer via `boss_defeated`, not at `_finish_event()`.** Routing through `_on_event_complete → _finish_event → _on_dungeon_complete` would re-show the world map, which is wrong for a run-ender. A dedicated signal + handler keeps terminal logic in one place. See `design.md — 2026-04-17`.
- **BossEvent extends CombatEvent.** All enemy / HUD / music / signal wiring inherits for free via `event is CombatEvent`. Only one extra connection is needed.
- **Shared `_teardown_current_event()` helper.** Extracted from `_on_event_complete()`; called by normal completion, player death, and boss victory so cleanup stays symmetric.
- **Level-up before victory.** If the boss kill grants enough XP to level, show the level-up panel first so the player can spend earned points, then show the victory panel.

## Blockers / struggles
