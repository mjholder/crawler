## Goals for this session

- [x] Change rider rarity from a runtime activation gate to pool metadata

## What I worked on

Reworked how rider rarity is interpreted. Previously `RiderData.min_rarity` was a runtime
gate: `ItemInstance.effective_riders()` filtered out any rider whose `min_rarity` exceeded the
instance's rarity, so a rider could sit attached but inert. Now rarity is **pool metadata** — it
classifies which rarity pool a rider belongs to, and generation grabs from the matching pool.

- `scripts/rider_data.gd` — `min_rarity` → `rarity`; rewrote the doc from "gate" to "pool tag".
- `scripts/item_instance.gd` — `effective_riders()` drops the rarity comparison and just returns
  every non-null rider; updated the `riders` var doc.
- `scripts/equipment_data.gd` — `base_rarity` doc reverts to "scaling tier only"; a baked rider now
  applies regardless of it (no more silently-inert baked riders).
- `scripts/rider_pool.gd` — **new** `RiderPool` (mirrors `FloorEventPool`): scans
  `resources/riders/`, buckets by `rarity`, offers `pool_for(rarity)` / `pick_of_rarity(rarity, rng)`.
- Comment cleanups in `scripts/player.gd` and `scripts/tag_data.gd` (dropped "rarity-gated" wording).
- Migrated the three rider `.tres` (`min_rarity → rarity`); regenerated `schema.json` (`make schema`);
  updated `tools/content_editor/docs/mcp-authoring.md`.
- Journals: logged the decision in [[design.md]] and added Phase 24 + fixed the class-diagram field
  in [[architecture.md]].

## Outcomes

### Completed
- Rider rarity is now pool metadata; the runtime gate is gone; `RiderPool` provides the draw API.
- All changed/new scripts parse clean (`--check-only`); schema regenerated with `rarity`.

### Incomplete / deferred

## Key decisions made

Rider rarity is pool metadata, not a runtime activation gate — one axis, one job: rarity selects the
pool, the pool decides the rider, an attached rider always applies. See [[design.md]] — Rider rarity
is pool metadata.

## Blockers / struggles

scripts, so `make schema` picked up the field rename automatically.
