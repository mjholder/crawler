## What I worked on

- Diagnosed and fixed four bugs in the content editor:
  - `proc_effects` showing `[object Object]` — schema annotation inheritance was broken; derived classes like `WeaponData` lost inherited `element_type` from `EquipmentData`. Fixed `export_schema.gd` to walk the ancestor chain and merge annotations.
  - Attack effects showing "(none)" — `listByClass("Effect")` returned nothing because no `.tres` has `script_class="Effect"`. Added subclass-aware `listByClassWithSubclasses` that resolves the transitive closure from `schema.json` and unions file lists for all concrete subclasses.
  - Inline sub-resources hidden by dropdown — `ResourceRefField` defaulted `showInline` to `false`, so existing inline values were masked. Fixed to render `InlineResourceEditor` immediately when the loaded value is inline.
  - Paper doll / sprite asset fields showing "(none)" — `Texture2D`, `AudioStream`, `PackedScene` have no `.tres` counterparts. Added `asset-index.ts` (new) + `/assets` endpoint in the sidecar; frontend uses `api.listAssets` for builtin resource types.
- Rewrote `StatDictField` from "all enum values as rows" to add/remove entry widget (unused-stat dropdown, integer input, × button, `+ Add stat` button).
- Regenerated `schema.json` after the annotation inheritance fix; verified `WeaponData.proc_effects.element_type = "ProcDef"` and inherited stat/effect fields all correct.
- Extracted all inline `Effect` sub-resources from 7 parent `.tres` files into 10 standalone files in `resources/effects/`. Updated all parents to use `[ext_resource]` refs. Round-trip verified all 10 via `io_read.gd`.
- Fixed 400 error on new resource creation — `apiFetch` was setting `Content-Type: application/json` on every request including no-body POSTs; Fastify rejects that. Now only sets the header when a body is present.
