## Key decisions made

- Player classes are pure data (`PlayerClassData` resource) — no code per class
- `max_health` is derived: `(CON * health_modifier) + class_health_bonus`, no longer an `@export`
- `base_damage` removed from Player — unarmed weapon resource will handle it
- XP curve: `xp_base * pow(xp_growth_factor, level - 1)` with exported tuning vars
- Level-ups grant 3 free distributable points + class auto-growth bonuses
- Level-up UI shown between events (end of `_on_event_complete`), not mid-combat
- Starting equipment fully equipped (not in bag) — see detailed design doc
