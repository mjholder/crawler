## What I worked on

The big class stat rebalance from [[ideas/attribute-distribution-leveling]].

- **All 8 class `.tres`** (`resources/classes/*.tres`) rebased: base 10 on the 5
  attributes, class-chosen primary +15 (→25) and two secondaries +5 (→15). Growth rates
  set to primary +6/lvl, each secondary +3/lvl. Primary/secondaries picked per class:
  Assassin AGI / LCK+STR, Duelist AGI / STR+CON, Hexer SPI / LCK+CON, Mage SPI / AGI+LCK,
  Pyromancer SPI / CON+LCK, Templar STR / CON+SPI, Warrior STR / CON+LCK, Winddancer
  AGI / LCK+SPI.
- **Defense refactor.** Removed `@export var defense` from `player_class_data.gd`;
  `player.gd` no longer copies defense from the class and its base `defense` defaults to
  0.0; `character_creation_panel.gd` `_build_stats_text` now lists only the 5 attributes.
  Deleted the `defense = X` line from every class `.tres`. Kept the `Enums.Stat.DEFENSE`
  slot and the armor-buffer mechanic (`_apply_defense` / `max_armor` / `brace_effect`)
  intact — defense now comes purely from equipment `stat_modifiers`.
- **Content editor.** Regenerated `tools/content_editor/schema.json` (`make schema`) —
  dropped the now-stale `PlayerClassData.defense` field (and two already-removed
  `class_*_bonus` fields the schema was stale on).

## Key decisions made

  equipment-derived value (like max HP / max mana). Enum slot kept to avoid renumber /
  save / effect-`stat_modifiers` breakage. Worth a [[design.md]] entry.
