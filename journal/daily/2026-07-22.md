## What I worked on

The big class stat rebalance from [[ideas/attribute-distribution-leveling]].

- **All 8 class `.tres`** (`resources/classes/*.tres`) rebased: base 10 on the 5
  attributes, class-chosen primary +15 (→25) and two secondaries +5 (→15). Growth rates
  set to primary +6/lvl, each secondary +3/lvl. Primary/secondaries picked per class:
  Assassin AGI / LCK+STR, Duelist AGI / STR+CON, Hexer SPI / LCK+CON, Mage SPI / AGI+LCK,
  Pyromancer SPI / CON+LCK, Templar STR / CON+SPI, Warrior STR / CON+LCK, Winddancer
  AGI / LCK+SPI.
- **Defense refactor.** Removed `@export var defense` from `player_class_data.gd`;
  `player.gd` no longer copies defense from the class and its base `defense` defaults to
  0.0; `character_creation_panel.gd` `_build_stats_text` now lists only the 5 attributes.
  Deleted the `defense = X` line from every class `.tres`. Kept the `Enums.Stat.DEFENSE`
  slot and the armor-buffer mechanic (`_apply_defense` / `max_armor` / `brace_effect`)
  intact — defense now comes purely from equipment `stat_modifiers`.
- **Content editor.** Regenerated `tools/content_editor/schema.json` (`make schema`) —
  dropped the now-stale `PlayerClassData.defense` field (and two already-removed
  `class_*_bonus` fields the schema was stale on).

**Combat legibility — action preview (second half of the session).** First player-facing
surfaces for [[ideas/player-facing-legibility]] (items 1 + 5).

- **`AttackPreview`** (`scripts/attack_preview.gd`, new `RefCounted`) — the single shared
  computation. `compute(action, source)` walks an attack/spell's `effects` into typed
  `Line`s (`DAMAGE`/`STATUS`/`HEAL`/`BUFF`), **reusing `StatExprEval`** so numbers match the
  runtime hit (non-crit, no armor mitigation — the raw hit). Exposes `total_damage()`,
  `status_lines()`, `tooltip_body()`, and a static `humanize_expression()` that rewrites
  `strength * 0.5` → `STR × 0.5` (surfaces the scaling stat — item 5).
- **Target overlay** — the user's hand-built `scenes/target.tscn` (Control) now drives the
  targeting reticle via new `target_reticle.gd`, replacing the code-drawn `TargetIndicator`
  `Node2D` (deleted). `game._spawn_indicator` instantiates it onto each candidate enemy and
  calls `set_preview(...)`, filling `TargetLabel` (computed damage) and the `Statuses` strip
  (status icons; badge = target's existing stacks + granted). `TargetTexture` left empty for
  future reticle art (per decision).
- **Action-button tooltip** — `GUI.set_preview_source($Player)` hands the GUI a read-only
  stat source; `_build_action_tooltip` composes name + target mode + `tooltip_body()` into
  each `ActionButtonUI` hover tooltip (`configure(..., p_tooltip)`).

  equipment-derived value (like max HP / max mana). Enum slot kept to avoid renumber /
  save / effect-`stat_modifiers` breakage. Worth a [[design.md]] entry.
