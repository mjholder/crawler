## Key decisions made

- `_finish_event()` forks on `_active_world_node != null` — when in a dungeon run it advances the queue; when null (debug paths) it returns to main menu. Keeps old debug entry points working without modification.
- Inherited scenes in Godot only inherit children that existed in the base at creation time. Going forward: always build the base scene fully before creating inherited scenes.

## Blockers / struggles

- `connected_nodes` NodePaths are stored on WorldMapNode and are relative to the WorldMapNode, not to WorldMap. `get_node()` called on WorldMap resolved them from the wrong root. Easy fix once the error made it obvious.
