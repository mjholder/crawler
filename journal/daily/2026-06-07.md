## What I worked on

Implemented the **three-layer character identity** (Class + Background + Patron Saint), Phase 1.

- New resources: `scripts/background_data.gd` (`BackgroundData`) and `scripts/patron_saint_data.gd`
  (`PatronSaintData`); added `lineage_id: StringName` to `scripts/blessing_data.gd`.
- `scripts/player.gd`: new economy-multiplier + `_background`/`_patron`/`_patron_tier_index` fields;
  `initialize()` gained optional `background`/`patron` params; `_setup_background`/`_setup_patron`;
  `ascend_patron()` (Phase 2 hook); a background `stat_modifiers` term in `get_effective_stat`;
  `reset_run_state` + save/load coverage. Moved the health/mana recalc to after layer setup so a
  background/saint CON shift counts toward starting HP (verified no existing class is affected).
- Wiring: `game.gd._apply_rewards` applies `gold_reward_multiplier`; shop buy/sell multipliers injected
  into the shop event's `data` dict and stacked in `shop_event.gd`; `game.gd._on_character_created` and
  `gui.gd` signal chain forward `background`/`patron` (all default `null`, back-compatible).
- UI: rebuilt the `CharacterCreationPanel` subtree in `scenes/game.tscn` as a hand-built 4-step wizard
  (Class → Background → Patron Saint → Confirm), anchored full-rect with `ScrollContainer` info panels
  so it resizes with the viewport; rewrote `scripts/character_creation_panel.gd` for step navigation,
  directory auto-loading, info builders, and per-step gating.
- Content editor: added both scripts to `export_schema.gd` `RESOURCE_SCRIPTS`, annotated
  `annotations.json`, added two `CONTENT_TYPES` rows in `frontend/src/types/schema.ts`, ran
  `npm run schema` (28 classes). Both types are pure schema-driven — no React changes.
- Sample content: `failed_business_owner.tres` and `saint_of_ambush.tres` + three tier blessings
  (`ambush_tier1..3`, tier 3 with a heal-on-kill subscription).
- Skills: `/create-background` and `/create-saint`.
- Docs: [[design.md]] decision entry, [[architecture.md]] (data-model diagram + Phase 9 prose + flow),
  [[detailed/character.md]] (new resource sections + wizard flow), `CLAUDE.md` Key Files.

## Key decisions made

See [[design.md]] — *Three-layer character identity: Class + Background + Patron Saint*. Patron saint =
`PatronSaintData` wrapper + `lineage_id`; background = hybrid (signed `stat_modifiers` + optional
`passive` blessing + explicit economy floats); creation UI = hand-built wizard; shrine ascension
deferred.
