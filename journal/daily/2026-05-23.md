- Implemented authored dungeon floor system (content editor v4):
  - Created `scripts/dungeon_floor_data.gd` — `DungeonFloorData` resource with `tags: Array[String]` and `slots: Array`.
  - Created `scripts/floor_slot.gd` — single polymorphic `FloorSlot` resource with `SlotType` enum (FIXED / RANDOM_TYPE / WEIGHTED) and all three modes' fields; `resolve(rng, pool)` dispatches by type.
  - Created `scripts/weighted_entry.gd` — `WeightedEntry` resource for weighted pool entries (event or event_type + weight).
  - Created `scripts/floor_event_pool.gd` — `FloorEventPool` runtime helper; builds floor pool + per-type event index from `res://resources/dungeon_floors/` and `res://resources/events/*/` at world-map load.
  - Rewrote `scripts/dungeon_map_node.gd` — stripped all per-type json_dir/scene exports; added `floor: DungeonFloorData`, `floor_tags: Array[String]`, `_resolved_event_configs`; `resolve_floor(rng, pool)` caches the result; `generate_event_configs()` just returns it.
  - Updated `scripts/world_map.gd` — builds `FloorEventPool`, creates seeded RNG (`run_seed` export, 0 = randomize), resolves all `DungeonMapNode` children at `_ready()`.
  - Created `resources/dungeon_floors/standard_short.tres`, `standard_medium.tres`, `scripted_demo.tres` — starter pool with tags `["short"]`, `["medium","mixed"]`, `["demo"]`.
  - Registered `FloorSlot`, `WeightedEntry`, `DungeonFloorData` in `export_schema.gd`; added annotations for `slots` and `entries` element types; regenerated schema (26 classes, 9 enums).
  - Added "Dungeon Floors" entry to `CONTENT_TYPES` in `frontend/src/types/schema.ts`.
  - Frontend build clean (206 modules).
  - Logged [[design.md]] entry on the polymorphic slot design and headless class-registration constraint.
