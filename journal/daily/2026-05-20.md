## Key decisions made

- **Godot headless sidecar over hand-rolled .tres parser** — `ResourceLoader`/`ResourceSaver` is the only correct parser; tool invokes Godot per read/write (see [[ideas.md]] for full rationale)
- **Temp-file write path** — `io_write.gd` reads JSON from a temp file passed as arg rather than stdin; `OS.read_string_from_stdin()` has a 1024-char default buffer that truncates larger resources
- **UID header patch** — `ResourceSaver` in headless mode silently omits `uid=` from the `[gd_resource]` header; `io_write.gd` reads the written file and patches the UID back in using `ResourceLoader.get_resource_uid()`
- **Inline vs. ext-resource detection** — Godot sets sub-resource paths to `parent.tres::SubId` (not empty string); `io_read.gd` now checks for `::` in `resource_path` to identify inline sub-resources
- **Built-in type sub-resources skipped on write** — `SpriteFrames`, `AtlasTexture`, etc. have no script path; `io_write.gd` returns null for these (preserving the loaded resource's value rather than corrupting it)
- **Diff noise accepted** — Godot reformats properties and corrects stale paths on save; this is intentional (stale paths → correct paths is actually a fix)

## Blockers / struggles

- Variant inference warnings treated as errors in Godot 4.6 strict mode — several `:=` declarations needed explicit types (`var s: Script = resource.get_script() as Script`)
- Engine startup banner goes to stdout (not stderr) in headless mode — sidecar strips by finding the first `{` in output
